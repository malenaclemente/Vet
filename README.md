# MisMascotas

# Descripción

MisMascotas es una aplicación integral diseñada para facilitar la forma en que los propietarios gestionan la información de sus mascotas y acceden a servicios veterinarios. La plataforma permitirá crear perfiles de mascotas, acceder a historiales clínicos, agendar citas, localizar veterinarias, recibir notificaciones de cuidados y facilitar la comunicación entre propietarios y profesionales veterinarios.

# Gestión de inicio de sesión de usuarios

1. **Iniciar sesión:** Permite al usuario autenticarse en la aplicación según su rol (Dueño o Veterinaria) validando sus credenciales de acceso. - Realizado✅
2. **Cerrar sesión:** Permite al usuario activo finalizar su sesión de forma segura y restringir el acceso a los datos de la cuenta. - Realizado ✅
3. **Recuperar contraseña:** Permite al usuario solicitar las instrucciones de recuperación ingresando su correo electrónico registrado. - Pendiente ⛔

# Gestión de Mascotas y Pacientes

1. **Consultar el listado de mascotas/pacientes:** Permite listar todas las mascotas registradas a cargo del dueño o los pacientes en seguimiento para la veterinaria. - Realizado✅
2. **Registrar una nueva mascota:** Permite dar de alta el perfil de un animal ingresando sus datos identificatorios, biológicos y de salud. - Realizado✅
3. **Consultar la ficha integral de una mascota:** Permite inspeccionar en detalle la información biológica, planes de alimentación, alergias, vacunas y consultas clínicas previas organizadas por pestañas. - Realizado✅
4. **Modificar y eliminar los datos de una mascota:** Permite editar los datos generales, peso, edad, restricciones alimentarias y pautas de nutrición del animal como también eliminar la mascota en su totalidad. - Realizado✅
5. **Registrar una consulta clínica en el historial:** Permite asentar una nueva visita médica en la ficha del paciente detallando fecha, motivo, diagnóstico, tratamiento e identificación del profesional actuante. - Realizado✅

# Gestión de Perfiles

1. **Eliminar cuenta de usuario:** Permite dar de baja de forma definitiva el perfil y acceso del usuario en el sistema. - Pendiente ⛔
