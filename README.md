# MisMascotas

# Descripción

MisMascotas es una aplicación integral diseñada para facilitar la forma en que los propietarios gestionan la información de sus mascotas y acceden a servicios veterinarios. La plataforma permitirá crear perfiles de mascotas, acceder a historiales clínicos, agendar citas, localizar veterinarias, recibir notificaciones de cuidados y facilitar la comunicación entre propietarios y profesionales veterinarios.
